# Team Board Application (Java)

A command-line noticeboard application written in Java. This program manages team announcements, allows filtering by captain names, supports case-sensitive and case-insensitive keyword searches, and tracks text data processing using core algorithmic logic.

## Features
- Notice Management: Post up to 10 notices with associated captain names and message contents.
- Display Options: View all posted notices in chronological order or reverse order, along with current capacity tracking.
- Advanced Searching: 
  - Search for all notices posted by a specific team captain.
  - Perform case-sensitive and case-insensitive keyword searches across all notices.
- Data Analysis: Automatically calculate the total number of digit characters present across all notice contents.

## How to Compile and Run

Make sure you have the Java Development Kit (JDK) installed.

Compile:
javac TeamBoard.java

Run:
java TeamBoard
